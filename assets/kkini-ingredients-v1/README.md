# 끼니 샌드위치 재료 에셋 v1

카테고리별 투명 PNG 시트 6장과 자동 분리한 724×724 PNG 28개입니다.

## 시트 순서

- `01-bread-sheet.png`: 우유식빵, 통밀빵, 호밀빵
- `02-spread-sheet.png`: 마요네즈, 머스터드, 페스토, 딸기잼, 무화과잼
- `03-main-sheet.png`: 햄, 칠면조햄, 닭가슴살, 달걀, 패티
- `04-cheese-sheet.png`: 체더, 스위스, 모차렐라, 리코타, 크림치즈
- `05-vegetable-sheet.png`: 양상추, 루콜라, 토마토, 오이, 아보카도
- `06-point-sheet.png`: 피클, 견과류, 꿀, 허브, 새싹

## 개별 파일

`individual/` 아래에 카테고리별 영문 파일명으로 정리되어 있습니다.

## 제작 규칙

- 얼굴과 캐릭터 요소 없음
- 둥글고 친근한 3D 제품 일러스트
- 정면에서 약간 내려다보는 동일한 조립 각도
- 얇은 A형 식빵 기준
- 모바일 화면에서 구분되는 색과 실루엣
- 샌드위치 층으로 겹칠 수 있는 낮은 높이

## v1 검수 메모

- 빵, 메인, 채소는 형태와 분리가 비교적 안정적입니다.
- 스프레드 개별 분리본 일부에는 인접 재료 가장자리가 소량 포함되어 있습니다.
- 치즈와 포인트 시트에는 흰색 매트가 남은 부분이 있어 최종 투명 에셋으로 사용하기 전에 개별 재생성이 필요합니다.
- 현재 버전은 전체 무드와 재료 형태를 확인하기 위한 1차 시안입니다.
