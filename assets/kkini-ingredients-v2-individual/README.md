# 끼니 샌드위치 개별 재료 에셋 v2

샌드위치 조합 화면에서 레이어로 겹쳐 사용할 수 있도록 각 재료를 개별 PNG로 제작한 세트입니다.

- 최종 사용본: `final/`
- 규격: 1024 × 1024 px
- 배경: 투명 PNG
- 시점: 살짝 위에서 내려다본 정면 3/4 시점
- 스타일: 얼굴 없는 둥근 3D 제품 일러스트
- 전체 검수 시트: `preview-all-28.png`
