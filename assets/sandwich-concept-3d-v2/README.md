# 끼니 샌드위치 3D 에셋 v2

사용자가 제공한 공모전 시안 이미지를 **스타일 레퍼런스**로 삼아 새로 생성한 투명 PNG 에셋입니다. 원본 시안 안의 텍스트나 UI 요소는 에셋에 포함하지 않았습니다.

## 캐릭터·샌드위치

- `01-balanced-sandwich.png` — 최종 제안·균형형 대표 이미지
- `02-overloaded-diagnostic-sandwich.png` — 현 상태 진단용, 층이 분리된 불안정 샌드위치
- `03-loan-priority-sandwich.png` — 대출 우선형
- `04-education-priority-sandwich.png` — 교육 우선형
- `05-retirement-priority-sandwich.png` — 노후 우선형
- `06-toast-clipboard-mascot.png` — 고객정보 입력 안내 캐릭터
- `07-chef-cat-advisor.png` — 레시피 제안·도움말 캐릭터

## 목표 아이콘

- `08-goal-icons-strip.png` — 5개 아이콘 한 줄 세트
- `09-icon-mortgage.png` — 주택대출
- `10-icon-education.png` — 자녀 교육비
- `11-icon-parent-support.png` — 부모 부양비
- `12-icon-retirement.png` — 노후 준비
- `13-icon-emergency.png` — 비상자금·기타

## 사용 메모

- 모든 파일은 RGBA 투명 PNG입니다.
- 샌드위치 캐릭터는 시나리오 카드, 진단 결과, 최종 제안 영역에 사용합니다.
- 개별 아이콘은 512×512로 정리되어 카드·배지·범례에 바로 넣을 수 있습니다.
- 글자와 수치는 이미지에 합성하지 않고 UI 레이어에서 별도로 배치하는 것을 권장합니다.
