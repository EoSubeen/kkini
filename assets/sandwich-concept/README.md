# 끼니 샌드위치 컨셉 디자인 에셋

AFPK 공모전의 재무진단 서비스 **끼니**를 위한 샌드위치 비주얼 세트입니다.

## 파일

- `01-sandwich-hero.svg`: 표지·발표자료용 메인 일러스트
- `02-sandwich-diagnostic.svg`: 김샌드 님 예시값을 넣은 진단 화면형 그래픽
- `03-sandwich-icon.svg`: 앱 아이콘·파비콘·프로필 이미지용
- `04-sandwich-layers.svg`: 화면 구현 시 재조합 가능한 항목별 레이어 모듈
- 같은 이름의 `.png`: 문서·슬라이드에 바로 넣을 수 있는 래스터 버전

## 핵심 규칙

- 샌드위치 높이 = 월 지출 총액
- 월수입 기준선보다 올라간 부분 = 적자(토마토 레드)
- 각 재료층 = 부모 지원, 생활비, 대출, 보험, 연금 납입, 교육비
- 숫자가 바뀌면 레이어의 **세로 높이만** 바꾸고 색상 순서는 유지

## 팔레트

- Ink `#2B2A27`
- Cream `#FFF8E8`
- Bread `#F0B953` / crust `#C9862F`
- Living `#4F7B63`
- Deficit / parent support `#D95D50`
- Loan `#5B678A`
- Pension `#6DA9C7`
- Insurance `#F5D64E`

SVG는 투명 또는 단색 배경을 사용하므로 웹, 문서, 발표자료에서 크기 손실 없이 쓸 수 있습니다.
