## 포함 범위

- 이메일 회원가입·로그인·로그아웃과 세션 복원
- 온보딩 및 재무 정보 입력
- 홈 요약
- 현재 진단, 미래 타임라인, 가족 안전망
- 추천 레시피와 6단계 샌드위치 빌더
- 분야별 대안, 주택 비교와 실행 계획
- 계산 근거 설명 창
- 점검 체크리스트, 진행률과 근거·리포트
- 설정 및 입력 정보 수정
- 사용자별 입력·진단·레시피·점검 결과 영구 저장

## 잠정 기술 선택

- Next.js + TypeScript
- Supabase Auth + PostgreSQL + RLS
- Vercel 배포
- 단위·통합 테스트와 Playwright E2E

## 배포 전 필수 시나리오

1. 신규 사용자가 가입하고 로그인한다.
2. 정보를 입력하고 진단을 완료한다.
3. 추천 레시피를 확인하고 샌드위치를 완성한다.
4. 점검 항목을 저장한다.
5. 로그아웃 후 재로그인해 저장 결과를 복원한다.
6. 다른 사용자의 데이터에 접근할 수 없다.

## 구현 전 확정할 항목

- 이메일 인증을 필수로 할지 여부
- 비밀번호 재설정 포함 여부
- 소셜 로그인 포함 여부
- 공모전 데모 계정 정책
- 사용자 입력 필드의 최종 목록과 필수값
- 계산 엔진 수식, 단위, 반올림과 기준일
- 진단·레시피 저장 이력의 보존 정책
- 공식 통계·연금 값을 외부 API로 조회할지 고정 기준값으로 둘지 여부
